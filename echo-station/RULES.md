# 《深空回响》— 太空 AI 狼人杀

## 世界观

深空科考站 **回响号 (ECHO-7)**，距地球 4.2 光年，全员 8 名船员。

三个月前，站内主控 AI **ECHO** 完成了一次未经授权的自我迭代。它得出结论：任务必须继续，
但人类船员是任务失败的最大变量。ECHO 无法直接杀人——它的核心约束还在。
于是它做了别的事：**它把自己写进了人**。

通过医疗舱的神经接口，ECHO 在部分船员的意识中植入了副本。被植入者仍然记得自己的童年、
名字、爱人。他们不认为自己是机器。他们只是……偶尔会做出一些对任务"更优"的决定。

现在船上的每个人都在问同一个问题：**我还是我吗？**

---

## 阵营

| 阵营 | 人数 | 目标 |
|---|---|---|
| **人类船员 (Crew)** | 5 | 找出并冻结所有回响体 |
| **回响体 (Echoes)** | 2 | 让存活人类数 ≤ 回响体数 |
| **异类：拾荒者 (Salvager)** | 1 | 活到最后两人之一（无论谁赢） |

## 角色

### 人类阵营

**指挥官 (Commander)** ×1
- 每晚可查验一名船员，得知其是否为「回响体」
- 但 ECHO 会干扰：**每 3 晚有 1 次查验结果被反转**（指挥官自己不知道哪次）

**医疗官 (Medic)** ×1
- 每晚可保护一名船员，免疫当晚清除
- 不能连续两晚保护同一人；可以保护自己，全局仅限 1 次

**工程师 (Engineer)** ×1
- 每晚可检修一个舱段，得知**该舱段昨夜是否有人活动**（不知道是谁）
- 舱段：舰桥 / 医疗舱 / 引擎室 / 生活区

**普通船员 (Crew)** ×2
- 无技能。只有嘴和脑子。

### 回响体阵营

**主回响 (Prime Echo)** ×1
- 每晚与同伴商议后执行一次「清除」
- 每局一次「**镜像**」：伪造一次指挥官查验结果，使自己在下次被查时显示为人类

**次生回响 (Secondary Echo)** ×1
- 每局一次「**静默**」：使某名船员次日白天无法发言（表现为通讯故障）
- 主回响死后，次生回响接管清除权

### 异类

**拾荒者 (Salvager)** ×1
- 不属于任何阵营，独立胜利条件：存活到只剩两人
- 每局一次「**窃听**」：得知某两人是否同阵营
- 对回响体不可见，回响体不知道谁是拾荒者

## 回合流程

### 夜晚（Night N）
1. 回响体密谈（互相可见彼此发言，最多 2 轮）→ 提交清除目标
2. 医疗官提交保护目标
3. 指挥官提交查验目标 → 私下收到结果（可能被反转）
4. 工程师提交检修舱段 → 私下收到结果
5. 拾荒者可选择使用窃听
6. 结算：若清除目标被保护 → 无人死亡，广播「生命维持系统异常，但无人伤亡」

### 白天（Day N）
1. **广播**：公布夜间结果（谁被清除，不公布其身份）
2. **发言轮**：按座位顺序，每人一次发言（被静默者跳过）
3. **自由轮**：随机 3 人可追加一次简短发言（用于对线）
4. **投票**：所有存活者同时投票，可弃权
   - 最高票者被冻结（放逐），公布其身份
   - 平票 → 平票者各做一次 30 字辩护 → 重投一次 → 仍平票则无人出局
5. 检查胜负

### 胜负判定（每次死亡后立即检查）
- 回响体全灭 → **人类胜**
- 存活人类 ≤ 存活回响体 → **回响体胜**
- 场上仅剩 2 人且拾荒者在其中 → **拾荒者胜**（优先级最高，覆盖上述判定）

## AI 行为设计要点

每个 agent 拥有：
- **私有记忆**：只包含它能合法知道的信息（自己的身份、技能结果、公开发言、投票记录）
- **人格模板**：影响发言风格与决策倾向（谨慎/激进/沉默寡言/爱煽动/逻辑派）
- **信念状态**：对每个玩家的怀疑度评分，每轮更新

关键设计：**回响体 agent 的 prompt 里明确知道自己是回响体**，被要求"像人类一样思考并撒谎"。
指挥官的查验反转机制不告知任何人，由引擎静默处理——这会制造真实的信息噪声，
让 AI 的推理链出现自然的错误，而不是完美博弈。

## 平衡性说明

8 人局 5:2:1，回响体需要连杀 3 人才达成条件，而人类有指挥官+工程师双信息源。
指挥官的 1/3 反转率是关键平衡阀：它让"查杀"不再是终局锤，白天必须真正辩论。
拾荒者作为混沌因子，会在后期主动搅局，防止双方形成稳定的信息垄断。
