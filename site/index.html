两个太空主题的社交推理游戏。共同的约束是： AI 玩家的推理必须建立在受限信息之上——信息隔离由引擎在数据层保证， 而不是在 prompt 里写一句「请不要使用你不该知道的信息」。

两种实现，同一个想法

目击是算出来的，不是发下去的

impostor-log 里每个 AI 每 0.5 秒记一条日记，saw 只包含同房间且距离小于视距的人。 断电时视距从 265 掉到 130，日记自动变模糊——信息噪声是从世界规则里长出来的，不是硬塞的。

引擎按 visible_to 分发

echo-station 里 agent 只能通过 visible_events(seat) 拿信息。 回响体的密谈、指挥官的查验结果，在数据层就到不了别人的上下文里。 7.6 万次可见性检查，零泄露。

行动也受限于同一份信息

AI 船员的怀疑度只从自己的日记里长出来（在场却不做任务 ↑、凭空消失 ↑↑、蹲在任务点 ↓）， 过线就放下任务跟上来盯梢。所以「假装做任务」当场就有回报，不必等到开会。

引擎不信任模型的任何返回值

空字符串、markdown 代码块、超范围数字、乱码——全部有强制校验和随机兜底， 400 局畸形输入压测零崩溃。而且兜底不是静默的：每局都会报出有多少次决策没能采纳模型返回值。

模型挂了游戏也要能玩

两个项目都保留了完整的规则 AI 作为降级路径，impostor-log 还做了主/备双端点 failover。 端到端测试专门覆盖「主端点 500 → 切备用」和「无配置 → 走规则」两条路。

平衡性是调过的

用不同推理准确率的模拟 agent 各跑 300 局，50/50 平衡点落在 35% 准确率附近。 关键阀门：回响体需要严格多于人类——早期版本用「不少于」，回响体胜率 85%。

cd impostor-log && python -m http.server 8000

# 深空回响 —— 不花钱先看一局：

uvicorn web.server:app --port 8100      # 实时观战界面
